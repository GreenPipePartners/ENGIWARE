FAQ

What is EngiWare?

EngiWare is an AI agent that helps you write and run engineering code with any AI model. It is available as a terminal-based interface on Linux and Windows through WSL2 and Winghostty.

How do I use EngiWare?

Run the install command above, then launch engicode from your terminal.

Do I need extra AI subscriptions to use EngiWare?

Not necessarily, EngiWare comes with a set of free models that you can use without creating an account. Aside from these, you can use any of the popular coding models by creating a Zen account. While we encourage users to use Zen, EngiWare also works with all popular providers such as OpenAI, Anthropic, xAI, and others. You can even connect your local models.

Can I use my existing AI subscriptions with EngiWare?

Yes, EngiWare supports subscription plans from all major providers. You can use your Claude Pro/Max, ChatGPT Plus/Pro, or GitHub Copilot subscriptions.

Can I only use EngiWare in the terminal?

EngiWare is currently designed around its terminal interface. On Windows, it runs in Winghostty through Ubuntu on WSL2.

How much does EngiWare cost?

EngiWare is 100% free to use. It also comes with a set of free models. There might be additional costs if you connect any other provider.

What about data and privacy?

Your data and information is only stored when you use hosted free models or create shareable links.

EngiWare is built on OpenCode by Green Pipe Partners.
